These split files are based off the splits used by CoPaint, which are based on those used in llama.

Since their results relied on an unseeded random shuffle for the train/validation split, we saved the shuffled file for reproducability.

The CelebA dataset used in our experiments was downloaded from https://www.kaggle.com/datasets/kimjiyeop/celebamask-256.

We made use of attributes from CelebAMask-HQ, which can be downloaded from links on https://github.com/switchablenorms/CelebAMask-HQ.
